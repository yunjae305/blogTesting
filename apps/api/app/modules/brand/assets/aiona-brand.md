# AIONA 브랜드 자료

이 문서는 AIONA 브랜드의 **전체 자료**다. 브랜드 자료의 `소개`·`핵심 기능` 칸에는 이것을
줄여 담고, 여기에는 줄이지 않은 것을 둔다 — 원고를 쓸 때 필요한 만큼 읽힌다.

**여기 없는 기능은 글에 쓰지 않는다.** 기능 이름은 실제 화면에 있는 글자 그대로이며,
원고가 이 이름을 그대로 쓴다. 한 글자만 달라져도 없는 기능이 글에 실린다.

---

## 1. AIONA란

AIONA(아이오나)는 "모든 AI, 하나의 구독으로"를 내건 **통합 AI 업무 플랫폼**이다.
25년간 네트워크·정보보안 분야에서 전문성을 쌓아 온 **윈즈(WINS)** 가 개발한 차세대
실행형 AI 에이전트 플랫폼이다.

기존 생성형 AI가 질문에 답하는 데 집중했다면, AIONA는 사용자의 최종 목표를 이해하고
필요한 작업을 스스로 계획·실행해 **실제 결과물까지 완성**하는 실행형 AI다.

ChatGPT, Claude, Gemini 등 여러 글로벌 AI 모델을 한 플랫폼에서 쓸 수 있는 멀티 LLM 통합
환경을 제공한다. 여러 AI 서비스에 각각 가입하거나 모델 특징을 직접 비교할 필요 없이,
요청의 목적과 난이도에 따라 적합한 모델이 자동으로 선택된다. 한국어의 표현과 문맥,
뉘앙스를 이해하도록 설계되어 복잡한 프롬프트 작성법을 익히지 않아도 자연스러운 질문만으로
결과를 얻을 수 있다.

### 핵심 가치 여섯 가지

| 가치 | 뜻 |
| --- | --- |
| 통합 | 여러 AI 모델과 업무 도구를 한 플랫폼에서 연결 |
| 자율 실행 | 요청을 이해하고 필요한 작업을 단계별로 수행 |
| 초개인화 | 사용자의 목적과 성향에 맞춘 AI 경험 |
| 업무 자동화 | 반복 업무를 예약하고 결과물을 자동 전달 |
| 안전한 활용 | 기업·공공기관에서도 쓸 수 있는 보안 환경 |
| AI 민주화 | 개발 지식 없이 누구나 자신만의 AI 서비스 제작 |

### 쓰이는 곳

개인의 일상과 학습을 돕는 **AI 생활 비서**부터, 기업의 리서치·문서 작성·지식 관리·업무
자동화를 지원하는 **엔터프라이즈 AI 플랫폼**까지 폭넓게 쓰인다. 교육기관·기업·공공기관과
협력해 실제 업무와 교육 현장에 적용되고 있다.

## 2. 기능 전체

기능은 크게 일곱 축이다: **대화(채팅) · 완성형 도구 · 앱스튜디오 · 프로젝트 · 아카데미 ·
브리핑 · 작업실.** 여기에 커넥터와 보안이 뒷받침한다.

### 2.1 채팅

여러 글로벌 AI 모델을 한 창에서 골라 쓴다. 요청의 목적·난이도를 분석해 모델을 자동
추천한다.

- **여러 모델로 검색(MMC)** — 여러 모델에 동시에 물어 답을 비교한다.
- **프롬프트 코칭** — 애매한 질문을 다듬어 준다.
- **심층 리서치** — 여러 출처를 교차 확인해 **출처가 붙은** 조사 결과를 만든다.

### 2.2 완성형 도구 (9종)

| 도구 | 하는 일 |
| --- | --- |
| 이미지 생성 | 썸네일·배너·포스터·카드뉴스 등 |
| 동영상 생성 | 숏폼·릴스·홍보 영상 |
| 슬라이드 생성 | 제안서·강의자료·프레젠테이션 |
| AI 요약 | 유튜브·웹·PDF를 요약 |
| 고민상담소 | 성격이 다른 AI 5인이 다관점 조언 |
| AI 플래너 | 리서치에서 실행계획까지 |
| 미디어 일기 | 보고 들은 것을 기록으로 |
| 회의록 | 원문·녹음 → 개요·결정사항·실행과제 |

### 2.3 앱스튜디오

개발 지식 없이 나만의 업무 앱을 만드는 **노코드 제작소.** 앱 타입은 다섯이다 —
**대화(챗) · 폼 · 워크플로 · 퀴즈 · 에이전트.**

기본 제공 앱도 함께 쓴다.

- **생산성** — 자료 조사, 문서 요약, 번역, 이메일·메시지 작성, 회의 준비, 회의록 실행과제 정리
- **비즈니스 문서** — 보고서·회의록 작성, 영수증·경비 정리, 자기소개서 초안, 계약서·약관 핵심 짚기
- **라이프스타일** — 주간 식단 짜기, 리뷰 답글·후기 쓰기, 경조사 문구, 알림장 정리
- **안심·생활 보호** — 사기 문자 확인

### 2.4 프로젝트

계약서·매뉴얼·규정·보고서·논문을 올려 **그 문서를 근거로** 답하는 지식 공간. 팀과 함께
쓰고 워크플로로 자동화한다.

### 2.5 아카데미

- **학습 코치** — 시간표·강의자료 → 요약 노트·문제은행·복습 일정
- **커리어 코치** — 포트폴리오·자기소개서·모의 면접·채용 소식
- **리서치 코파일럿** — 논문 검색·비교·문헌 종합

### 2.6 브리핑

RSS·웹·유튜브 채널을 구독해 두면 **매일 아침** 핵심 소식을 자동 요약한다.

### 2.7 작업실

만든 결과물을 한곳에 모으고, 반복 작업을 **루틴**으로 걸어 정해진 주기마다 자동 처리한다.

### 2.8 커넥터

Notion · Google Drive · Slack · Google Calendar 등 업무 도구를 연결해 흩어진 정보를 한
대화창에서 쓴다.

### 2.9 보안

프롬프트 인젝션 탐지·차단, 유해 콘텐츠 필터링, 개인정보 자동 탐지 및 **외부 모델 전송 전
마스킹** 등 기업·공공기관용 보안 환경을 제공한다.

## 3. 이런 상황이면 이 기능

트렌드 소재에 AIONA를 **활용 도구로** 얹는 글이 여기서 기능 이름을 가져온다.
`feature` 칸의 이름은 실제 화면의 이름 그대로이며, 원고에 그대로 등장한다.

| 상황 | 기능 | 이 상황을 알아보는 말 |
| --- | --- | --- |
| 어떤 정보를 알아보고 싶을 때 | 자료 조사 | 다이어트, 칼로리, 성분, 신제품, 출시, 가격, 스펙, 효능, 차이점, 실제로 |
| 여러 자료를 교차 확인해 근거를 갖춰야 할 때 | 심층 리서치 | 시장, 동향, 경쟁사, 규제, 타당성, 전망, 점유율 |
| 긴 자료·뉴스·문서를 빨리 파악해야 할 때 | 문서 요약 | 보고서, 논문, 약관, 공시, 백서, 발표자료 |
| 유튜브 영상이나 웹 기사를 요약해야 할 때 | AI 요약 | 유튜브, 영상, 기사, 강의, 다큐 |
| 해외 자료를 확인해야 할 때 | 번역 | 해외, 외신, 직구, 해외여행, 영어, 일본, 미국, 유럽, 현지 |
| 회사에 보낼 글을 써야 할 때 | 이메일·메시지 작성 | 취업, 면접, 이직, 퇴사, 채용, 직장, 상사, 거래처 |
| 회의나 발표를 준비할 때 | 회의 준비 | 회의, 발표, 기획, 협업, 프로젝트 |
| 회의 내용을 정리해야 할 때 | 회의록 | 회의록, 녹취, 전사, 실행과제, 안건 |
| 발표 자료를 만들어야 할 때 | 슬라이드 생성 | 제안서, 피피티, 강의자료, 프레젠테이션 |
| 후기나 답글을 써야 할 때 | 리뷰 답글·후기 쓰기 | 리뷰, 후기, 평점, 별점, 사장님, 자영업, 매장 |
| 한 주 먹을 것을 미리 정해야 할 때 | 주간 식단 짜기 | 식단, 자취, 밀프렙, 단백질, 도시락, 장보기, 이유식 |
| 아이 학교·가정 알림을 정리할 때 | 알림장 정리 | 알림장, 학교 준비물, 학부모, 가정통신문, 방학 숙제, 초등 |
| 명절·행사·경조사 문구가 필요할 때 | 경조사 문구 | 명절, 설날, 추석, 결혼, 청첩, 부고, 돌잔치, 환갑 |
| 지원서나 자기소개서를 써야 할 때 | 자기소개서 초안 | 자소서, 자기소개서, 지원서, 공채, 인턴, 수시 |
| 계약서나 약관을 확인해야 할 때 | 계약서·약관 핵심 짚기 | 계약서, 약관, 전세, 임대차, 보험, 특약, 청약 |
| 영수증·지출을 정리해야 할 때 | 영수증·경비 정리 | 영수증, 경비, 지출, 정산, 연말정산, 가계부 |
| 의심스러운 문자를 받았을 때 | 사기 문자 확인 | 스미싱, 보이스피싱, 피싱, 사칭, 사기 문자 |
| 블로그·SNS에 쓸 이미지가 필요할 때 | 이미지 생성 | 썸네일, 배너, 포스터, 카드뉴스, 굿즈, 프로필 사진 |
| 짧은 홍보 영상이 필요할 때 | 동영상 생성 | 숏폼, 릴스, 홍보영상, 프로모션, 광고 영상 |
| 계획을 단계로 짜야 할 때 | AI 플래너 | 여행 일정, 로드맵, 실행 계획, 마케팅 전략, 일정표 |
| 결정이 어려워 여러 관점이 필요할 때 | 고민상담소 | 고민, 진로, 창업, 이직 고민, 선택 |
| 매일 반복하는 조사·정리가 있을 때 | 작업실 루틴 | 반복, 자동화, 매일 아침, 주간 브리핑 |
| 구독 채널 소식을 모아 봐야 할 때 | 브리핑 | 뉴스레터, 구독 채널, 소식 정리, 업계 소식 |
| 내 문서를 근거로 답을 얻어야 할 때 | 프로젝트 | 사내 규정, 매뉴얼, 지식베이스, 내부 문서 |
| 시험·과제를 준비할 때 | 학습 코치 | 시험, 과제, 중간고사, 기말, 학점, 복습 |
| 취업을 준비할 때 | 커리어 코치 | 포트폴리오, 면접 준비, 공모전, 취준, 스펙 |
| 논문을 찾고 비교해야 할 때 | 리서치 코파일럿 | 논문, 학술, 선행연구, 인용, 학회 |
| 개발 지식 없이 나만의 AI 앱을 만들 때 | 앱스튜디오 | 노코드, 챗봇, 업무 자동화, 사내봇 |

**표에 없는 상황이라고 AIONA를 못 쓰는 것은 아니다.** 이 표는 출발점이지 허용 목록이
아니다 — 소재와 관련된 기능이 위 2장에 있으면 그것을 쓴다. 다만 **2장에 없는 이름은
쓰지 않는다.**

## 4. 가입과 요금

- 가입은 **무료**, **웰컴 크레딧 100** 지급, **카드 등록 없음.**
- 구체적인 요금제·크레딧 소진 방식은 자주 바뀐다. **글에 숫자를 쓸 일이 있으면
  aiona.kr에서 그때 확인한 값을 쓴다** — 이 문서의 숫자를 그대로 옮기지 않는다.

## 6. 글을 쓸 때

- AIONA는 대개 **글의 주인공이 아니다.** 트렌드·소재가 주인공이고 AIONA는 그 과정에서
  쓴 도구로 등장한다(본문의 약 20%).
- 홍보하지 않는다. "알아보다가 AIONA에 이런 기능이 있어서 한번 써 봤더니 도움이 됐다"에
  가깝게 쓴다.
- 권유는 글 맨 끝의 안내 한 줄에서만 한다.
